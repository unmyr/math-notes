== Local build setup

Add the following setting to your VS Code user `settings.json`.

* Windows
+
[source,json]
----
{
  "docs.outputBaseDir": "C:\\path\\to\\docs"
}
----

Then run the build task in VS Code.

The build output will be written to `<docs.outputBaseDir>\<repository-name>`.
